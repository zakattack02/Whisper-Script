⚠ Whisper Binary Setup Required
The whisper-cli binary is bundled with the plugin but must be manually copied to the cache directory:
# Copy binary from plugin directory to cache
sudo cp ~/.config/jellyfin/plugins/Whisper\ Subtitles_*/whisper/linux-x64/whisper-cli ~/.cache/whisper-cpp/
sudo chmod +x ~/.cache/whisper-cpp/whisper-cli
Replace ~/.config/jellyfin with your Jellyfin config path if different. Adjust paths for macOS (~/Library) or Windows (AppData\\Roaming\\Jellyfin).
