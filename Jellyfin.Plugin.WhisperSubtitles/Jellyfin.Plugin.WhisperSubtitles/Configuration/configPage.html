⚠ Whisper Binary Setup Required
The whisper-whisper-cli binary is bundled with the plugin but must be deployed to the cache directory. Click Install Binary below, or run manually:
sudo cp ~/.config/jellyfin/plugins/Whisper\ Subtitles_*/whisper/linux-x64/whisper-whisper-cli ~/.cache/whisper-cpp/
sudo chmod +x ~/.cache/whisper-cpp/whisper-whisper-cli
Replace ~/.config/jellyfin with your Jellyfin config path if different.
